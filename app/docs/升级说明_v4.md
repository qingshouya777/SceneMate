# 产品3 · v4 落地说明

`产品2` 是按 v3 那套"正面临时补丁"长出来的：目的系统 + 地标系统 + 一条 `current_note_for()`
里塞了 300 行按最近台词反推的禁令。`产品3` 换成 v4 负面契约，并把 §3 清单上的
A/B/C/D 全部落进代码——不是把契约文当一个 md 贴着，而是**每条机制都有代码判据**。

一句话：**契约负责让她想明白该怎么说话，代码负责不让她说出接不上的话。**

## 2. §3 逐项对照

### A. 三条机制

| # | 落地位置 | 怎么验 | 现状 |
|---|---|---|---|
| A1 强制引用自己上一句 | `contract.check_reference()` + `brain.validate()` + `brain.speak()` 内的一次重说 | `python tools/check_contract.py`；运行日志里的 `引:原词/动作/句内重合` | ✅ 不过就重说；两次都不过 → 这一格不说 |
| A2 pending 分档清算 | `router.pending_tick()` | 同上，4 格内请求/问自动清掉、记账型留 8 格 | ✅ 请求 age≥2 自兑现或作废；问 age≥2 转自问；记账型 TTL 8 |
| A3 句子落点自检 | `contract.landing_test()` | 同上：`灯亮了。`→违约，`跟不上，你慢点。`→通过 | ✅ 世界词表 + 「你/身体词」双通道 |
| 认亲边界（只算相邻帧） | `router.detect()` 欲望分支只比 tick-1；写进契约「认亲边界」一节 | `replay_router` 里欲望只在相邻两格连涨时触发 | ✅ |

A1 的做法值得单说：**不让模型自证，而是让它在【态】里填一个 `引用=` 字段**，收回来逐字比对
上一句原文。填「无」= 违约，填了原文里没有的词 = 违约。这样"有没有接上"从主观变成可判定。

### B. 视觉层

| # | 落地位置 | 验收 | 结果 |
|---|---|---|---|
| B1 分块读字 | `signals.text_proxy()`：8×6 粗格 → 命中块再 4×4 细化，输出命中位置 | 三帧必须命中 | ✅ 8=3.71 / 11=6.93 / 15=21.39（门槛 1.0） |
| B2 气泡独立事件 | `signals.find_bubble()` + `router._bubble_novelty()` | 9.png 必须命中 | ✅ 9=2.39，位置 0.562,0.625 正好是气泡 |
| B3 三环加置信度 | `signals.ring_estimate()`：主体面积×底边位置×局部清晰度，主体面积不足直接封顶 | 台阶不再被判贴身 | ✅ 见下 |
| B4 flow 绝对标定 | `signals.read/write_flow_baseline()` + `tools/calibrate_flow.py` | 标定后才有物理量 | ✅ 没标定 = **不许说「他停了」**（不是退回 6.0） |

**B1 为什么原来会漏**：整帧降采样到 160×100 再算"极亮/极暗笔画占比"，一块 20px 高的字
被平均掉了。分块后算的是同一个物理量，只是不再跨块平均——8.png 那块「FILMMORBIT」是灰字
压在暗红立面上，全帧只有 0.21，细化后单格 3.71。

**B2 为什么不能靠形状**：在这一版画面上，气泡和"黑底白字招牌"像素级同构，纯静态判据分不开
（试过连通块、形态学闭运算、积分图滑窗、行游程，都会把店招一起捞进来）。所以改成
**时间分辨**：气泡会消失，招牌不会。同一位置最近两格都在 = 招牌，不报。

**B3 修的是什么**：原来只看 `ctr_edge` 分位数，"一大片台阶"因为边缘多被判成"贴身"。
现在 `ctr_edge` 只占 0.42 权重，还要主体面积 ≥ 0.25、局部清晰度对得上；三项都弱时
`conf` 会掉下来，调度层就不用它。

### C. 调度层

| # | 落地位置 | 说明 |
|---|---|---|
| C1 滑动窗口基线 | `router.thresholds()` + `activity_report()` | 最近 24 格算分位，同时保留绝对地板；每格把「本段动度」（mean 区间/open 区间/flow 中位/文字命中数）写进 `调度.txt`，沉默可归因 |
| C2 线程优先 | `router.tick()` | 有活跃线程且没说满 → 先续锚；只有打断等级 ≥3 的事件能抢，且写进 `decision["preempt"]`（`调度.txt` 有"抢占留痕"） |
| C3 thread 结构 | `router._open_thread/thread_tick/thread_advance` | `{anchor, stance, stage, remaining, break_level}`；推进是**意图**的五步：升起→犹豫→改口→落空→认掉 |
| C4 pending 队列 | `router.pending` + `apply_resolution()` | 由调度层维护并落盘到 `memory.json` 的 `router` 段，重启不丢 |
| C5 revisit 回访 | `router._revisit()` | 与历史帧比 32×20 签名，间隔 ≥12 格（60s）且距离 ≤9 → `revisit` |
| C6 语言分支输入策略 | **已撤掉**（原 `contract.anchor_only_check()`） | 它只在 `lang` 上生效，而 `lang` 正是"让她讲一件新的事"的格子——它禁止的"新名词"恰好是故事必需的东西。实测把唯一一次真故事（"以前我七岁那年…"）判死。现在改用"故事模式不附图 + 不给信号块"来控制画面污染，见文末复盘 §7 |

**C2 的额外一刀**：读字很会开场，但一条商业街每格都有新招牌，让它无脑抢断，话题照样
活不过两句——只是换了个人来拐她。所以 `_preempt_allowed()` 区分了「开场等级」和「抢断等级」：
读字要笔画占比 ≥6 才许抢，普通招牌排队等下一轮。

### 连接页（这次新加的）

`设置 → 连接`，一个页面把「接谁、接到哪、用什么模型、key 放哪」全解决：

- **接入方**：下拉选。DeepSeek 排第一且是默认；其余七家都是 OpenAI 兼容接口，选中就自动填好 Base URL 和模型候选。
- **Base URL / 模型**：都能改。模型下拉可以手填，也可以点「拉取模型列表」在线拉（`GET {base}/models`）。
- **视觉提示**：预设里标了每个模型**看不看图**。选了 `deepseek-reasoner` 或 `moonshot-v1-32k` 这种不看图的，会直接红字警告"她会看不见画面"。
- **Key 两条路**：
  - 填进界面 → 点「保存到本机」→ 用 Windows DPAPI 加密写进 `keys.dat`（绑当前账户，文件拷走也解不开）；
  - 或者设环境变量（`DEEPSEEK_API_KEY` / `OPENAI_API_KEY` …），**优先级更高**。
  - `config.json` 里永远不会有 key，备份和打包都带不走。
- **测试连接**：两段。① 发一句纯文字确认接口通；② **发一张 96×96 的纯红图**问"这是什么颜色"——答得出红，才说明这个模型真的能看见。

## 附：2026-10-23 实跑复盘（四个 bug）

这一段是拿真实运行记录（19 格、6 条记忆）倒查出来的，不是猜的。

**1. 记忆里出现 `sign：「…」` 和三条一模一样的「看见：眼前（没说话）」**

- 根因：`memory._entry_line()` 把内部英文分支 id 当成了"地点"来渲染；`main` 里沉默一格写死了 `add_silent("眼前", …)`，占位符变成了内容；digest 又把每一格沉默单独列一行。
- 修：分支 id 走中文映射（sign→读字、bubble→有人说话…）；沉默不再写 scene；沉默合并成一句「这一段里你有 N 格没开口」；台词的多句连接从 `\n` 改成 `。`（记忆里不再存一段带换行的台词）。

**2. 19 格里有 7 格被「两次都说不住上一句」吞掉（37%）—— 元凶不是 A1，是 A3 和 C6 误杀**

- A3 只认「你」和一张很窄的身体词表。于是 `招财宝，左边那行红字我认得` 被判违约（她明明在叫他名字）；
  `我不想走了` 也被判违约（"走"当时不在词表里）。
- C6 的名词表里有 **门/窗/车/猫/狗/树/花/路/街** 这些单字，`门口站着个人`、`这条路走得有点烦`、`踩到花` 全被判成"拿了线程外的东西"；而且它在 `follow`（接话）上也生效，等于不让她把半句话说完。
- 修：A3 认称呼、认「我」（`灯亮了`「左边那行红字真亮」仍然违约，那才是导游腔）；C6 只留多字名词，且只在 `lang` 生效。

**3. 她从不讲故事（19 格里 `lang` 出现 0 次）**

- 根因一：读字/气泡/过渡把每一次开口机会都占了。`lang` 只有在"没事件 + 势能满"时才轮到，实际永远轮不到。
- 根因二：`60_输出格式` 写着「引用填你从上一句接住的那个词」，模型就理解成**句子要从那个词开头**，
  于是出现 `LEON」底下还有小字` 这种缝合句——它在复读，不是在讲事。
- 修：加「起话头」节奏（连着 4 次都在说画面 → 强制一次 `lang`）；`follow` 允许把话拐到自己身上；
  `lang` 明确要求**讲一件具体的小事**（几岁、什么季节、谁在场），不许总结成感慨；
  60 里写明「引用只写在【态】里，台词不必带上它，更不要从它开头」。

**4. 「跳过」连续两轮 —— 那不是她的行为**

- 那是**截帧闸门**：那一帧太黑或太糊，根本没送给模型（`capture.frame_gate`）。
  原来状态栏和日志都写「跳过」，看起来像她跳过了一格，其实是"没看"。
- 修：改成「这一格没看 · 画面模糊／过暗」，日志记「画面不清（没送模型）」。

**改完的验收**：`check_contract` 里 A3/C6 的用例全部重写并全绿；`replay_router` 跑测试1，30 格里
`lang` 出现 5 次（约每 6 格一次），`follow` 不再被杀掉。

**5. 「她没有上下文，每一格都像新的开始」（2026-10-23 晚，真模型两连跑查出来的）**

证据：连跑两格，第 2 格会滑到画面里另一样东西；提示词里还写着「这是你们第 2 次一起看画面」。

四个根因，都是会让她"重新开头"的东西：

- **锚点被引用词覆盖成动词。** 模型在【态】里填「引用=认出来」，`main` 就拿它当话题锚，下一格
  提示词变成「你现在挂在嘴边的是：认出来」——等于没有话题。
- **线程块写成了一句陈述句。** 「你现在挂在嘴边的是：刚才有人说话」——实测模型直接把
  「刚才有人说话」当成她的台词念了出来（日志里真出现过）。
- **会话切分太浅。** 走开 10 分钟就算"新的一次"，记忆抬头写「这是你们第 2 次一起看画面」，
  等于每次回来都告诉她：从头开始。
- **线程刚开就被抢走。** 一个招牌、一次亮度变化就能把刚说了一句的话题换掉。

修法：

| 改动 | 位置 |
|---|---|
| 锚点不再被引用词覆盖，她说到哪儿由 `stance` 记 | `main._work` |
| 线程块改成卡片：起因 / 你已经说到 / 走到哪步 / 还能说几格，并明写「不是台词，不要念出来」 | `router.thread_block` |
| 代码层兜底：整句照抄提示卡（「刚才有人说话」「这一片细节」）的直接丢掉 | `brain._is_echo` |
| 会话切分 10 → 30 分钟；删掉「第 N 次一起看画面」 | `memory` |
| 刚开的线程至少说两句才可被抢（气泡 / 他停下除外） | `router._preempt_allowed` |
| 上一句有效期 10 → 30 分钟，别走开一会儿就变「首句」 | `main._work` |
| `follow` 明确「画面里别的不是这一格的话题」；风格里加「一轮只说一件事」 | `65_分支.txt` / `20_风格.txt` |

验收（新增工具 `tools/check_continuity.py`，真模型连跑）：

```
t1 开·气泡   招财宝，那家冰淇淋店门口的字好大，我一眼就看见了
t2 续锚·接话  那粉色的，看着就甜得发腻
             我小时候吃冰淇淋，掉了一整只在地上，哭得我奶奶没办法
```

第 2 格接住了第 1 格，而且讲了一件具体的小事——这正是"有上下文"和"会讲故事"同时成立的样子。

**关于「跳过」**：那不是她的行为，是截帧闸门（那一帧太黑/太糊，没送模型）。现在代码、状态栏、
日志里都已经没有这个词；只有 20:49–20:50 那批旧日志还留着历史行。

## 附：和你那套「全围绕我」逻辑的对照

你说的那套是：**只给一张图 + 不给时间地点空间 + 图已经过去一秒 + 负面写法 + 所有话都围绕"我"（玩家）**。

| 你的要求 | v4 现状 | 差在哪 |

| 只给图片信息，其余靠推测 | 契约「你有的」第 1 条就是"只有这一张"，且明写没有时间/地点/空间 | ✅ 一致 |
| 图已经过去一秒 | 契约原文：「你输出这句话的时候，离这张图已经过去一秒左右了」 | ✅ 一致 |

### 差的那一处：落点

你的例子里，每一条都长这样：

> 这个咖啡店挺好看的，**你带我进去吧**
> 没想到还能看到樱花树……**难道这是你特意安排的路径吗？**

规律是：**画面只当由头，最后一句一定落在他身上**。而 v4 原来的 A3 只检查"整轮里有没有我/你"，
所以她可以说「那粉色的，看着就甜得发腻」——整轮过半，落点却停在画面上。

本轮加了 **A4 落点判据**（`contract.ends_on_him`）：只查**最后一句**，必须出现你/咱/我们/他的名字，
否则带理由重说一次。同时把这条写进契约的"说话的样子"。

真模型连跑三格（同一张图，模拟连续三个 tick）：

```
t1  那块黑底白字突然冒出来，吓我一跳，还以为谁在冲我喊 / 招财宝，你听见没？
t2  左边那家冰淇淋店，粉得跟假的似的，我盯着看了半天 / 你猜我小时候最想吃哪种
t3  那个粉的，上面还插着两根棍，我小时候就想要这种，一整桶抱在手里 / 你猜我最后吃到的是什么
```

三格同一个话题（那家粉店），每格都落在他身上，而且第三格真的讲出了具体的东西（插两根棍、一整桶抱在手里）。
三次都没有触发重说——A4 没有把产量压下去。

### 还有一处"我们比你说的多给了东西"

严格按你的说法是"我只能给你图片的信息"。但 v4 **还给了代码算出来的信号**：
`signals.py` 会把"这块字清楚到能读 / 有东西贴得很近 / 光换了一档 / 刚有人说话"写成一句"你身上的感觉"，
作为 `72_信号.txt` 塞进提示词。

这不是画蛇添足：读字和气泡靠纯图也能做，但命中率会明显掉（v3 就是这么漏掉 8/11/15 三帧的）。
如果你要**严格的纯图模式**，把 `contract.situation_lines()` 的返回值置空就行（一行），
代价是"读字/气泡/过渡"三个分支基本失灵。

### 一处你比契约更"敢"

你的例子里有「你带我进去吧」「我们继续散步吧」——**提议下一步**。
契约 §5 原来写过"她不能计划"，但 v4 的实际实现是允许的：契约明写"想让他陪你做什么…这是正事"，
`60_输出格式` 里也有 `+求"…"` 记账。她不能做的是**空间预测**（"再走两步就到"），
因为那需要她真的知道远近。这条界线目前是对的，改的时候别越过去。

### 顺手查出来的第七个 bug（他们没提到）

`clean_text()` 原来用 `strip("「」")` 去包在外面的引号，这会把**句中本来就有的收尾引号**一起吃掉：


两句会粘在一起，引号也没了。现在改成"只有整句从头到尾被一对引号包住才脱掉"。

### 他们建议的"六开关复现脚本"，换成了更便宜的做法

**6. 「两次都不过：没接住上一句」——判据自己的 bug（2026-10-23 深夜）**

日志里偶发这一行，然后那一格就静音了。查下来不是模型不会接，是 A1 的判定顺序写错了：

```python
if not ref or ref in ("无", ...):
    return {"ok": False, "how": "没写引用"}     # ← 第一行就判死，根本没看句子
shared = {b for b in _bigrams(line) & _bigrams(joined) ...}   # 兜底永远走不到
```

模型偶尔漏填【态】里的「引用」（尤其是短回复），A1 就判她"没接住"，重说一次还是漏 →
整格丢掉。而那一句很可能明明接着上一句（共用实词），只是没写字段。

同时还有一个同源的坑：状态行的解析只认 `｜` 和 `=`/`：`。模型换成 `＝`、`丨`、逗号、
或者空格分行（`情绪：平静 引用：手冷`）时，`引用` 根本读不出来，结果一模一样。

修法：

- **判定顺序反过来**：先看这一句跟上一句有没有共用实词，再看字段。缺字段但字面接上了，
  记 `推断:xx` 放过；两边都不成立才判断。
- **状态行解析放宽**：`＝ ﹕ 丨 ，` 都认；一段里塞了两个以上 key 时按逗号再切；
  最后给「引用」单独加一条兜底提取（空格分行也能捞出来）。

现在唯一还会被 A1 拦住的，是"她真的换了话题"——没有共用实词，也没有动作引用。
那是 A1 的本职，不该放宽。

**7. 「故事格」为什么一句故事都说不出来（2026-10-23 夜，实跑日志）**

调度层确实给过她机会——22:01:30：

```
t11 开 闲话 | 连着 10 次都在说画面，这一格让她自己起话头
```

紧接着日志：`闲话 · 沉默 · 两次都不过：没接住上一句/拿了新东西`。

四道锁同时锁着：

1. **A1** 要求"这一句接住上一句"——故事讲的是新事，天然接不上。
2. **C6** 禁止出现新名词——故事里必然有店、台阶、狗。
3. **A4** 要求最后一句落在他身上——故事的结尾是"我舔得满手都是"。
4. **最后一条 user 消息还是"看一眼，只说一句"**，而且信号块里写着"有一块字清楚到能读"——
   两句话都在把她往画面上拽。

（前三道是我们自己的判据，第四道是没意识到位置权重：最后一条消息最管用。）

改法——引入**故事模式**（`lang` 那一格，以及这条线程后面的续锚格）：

| 做法 | 为什么 |
|---|---|
| **不发图** | 画像是拽她回去的最大引力，直接撤掉 |
| 不给信号块、不给"接住上一句" | 少两句相反的指令 |
| 最后一条消息换成"讲一件以前的事，跟眼前没关系" | 位置权重最高的一句必须站在故事这边 |
| 提示词**最前面**加一句 story_note | 只写在分支块里（契约之后）压不住"刚才在聊的那件事" |
| A1 / A4 豁免（A3 保留） | 故事不接上一句，结尾也不落在他；但"不能变成纯景物描述"这条留着 |
| C6 删除 | 它管的正是"允许新内容"的那一格 |

实测（同一张图，连续两格强制故事格）：

```
七八岁那年夏天，我蹲在街口等那卖冰棍的，手里攥着两毛钱，狗就拴在旁边的电线杆上
一转头绳子空了，我顺着街找了半条，冰棍化在手里都没舍得扔

我八岁那年夏天，外婆家楼下有个卖凉粉的，我攥着五毛钱去排队，前面那人一让，我整碗扣在裙子上
```

**8. 「你倒是说句话啊」——契约漏了一条世界事实：他是哑的（2026-10-23 夜）**

记忆里抓到两句：

```
买就买吧。…看着像只做一回生意。你倒是说句话啊。
里面那个红脑袋的，正瞪着我呢…你倒是先开口，别让我一个人跟它对视。
```

游戏里主角从不开口。契约只写了「他在做什么我看不到」，没写「他不会说话」，
模型就按普通对话补了一个会回话的对象，还催他开口。

修：契约加一节——

> ## 他不会开口
> 他是哑的。你可以对他说话、问他、怼他、要他，但他永远不会用话回你。
> 所以别问他「你怎么不说话」，别等他答，也别替他答。问完就自己往下说。

顺带修的两处：

- **A1 放行「拐回忆」**：那句「墙上爬了那么多绿叶子，我小时候住的那种老街上也这样」
  本来是好句子，被「必须接住上一句」判死、整格吞掉。现在带「以前/小时候/记得/那年…」
  的句子直接放过，记 `拐回忆`。
- **输出格式加一条「别写半句」**：记忆里出现过「…我手心里全是汗，你别嫌。」
  ——不是代码截的（句子只有 20 字，离 60 字上限很远），是模型自己停在半截。现在格式里写明。

**关于「跳过」**：界面和代码里都没有这个词了（全局搜索 0 命中）。最容易和它混的是状态栏这两句：

| 状态栏 | 含义 |
|---|---|
| `这一格没看 · 画面模糊/过暗` | 截帧闸门挡了，**没送给模型** |
| `○ 没说 · 两次都不过：没接住上一句` | 送给模型了，但判据没过，重说也没过 |

实测 22:30 之后：**开口 6 / 沉默 2**。两条沉默都是 A1，其中一条就是上面那句回忆被误杀——已经修了。

**9. 严格条款置顶 + 一个被吞了很久的 bug（2026-10-23 深夜）**

要求：硬条款放开头，别让模型绕过去。


真模型三格：3/3 开口、零重说，两句到三句，落点都在他。

**10. 好感系统 + 三处措辞（2026-10-23 深夜）**

**好感怎么算**

- 判定交给模型：`【态】` 多了一个字段 `心动=是/否`——"这一格你看见的东西让你心里动了一下吗"。
- 数额由代码掷骰子：**心动=是 → +1~5**，她不能自己定价。
  权重偏小：**1~3 占 92%**（40/32/20），4~5 只占 8%（6/2）——
  偶尔来一次大的才像真的，天天 +5 会麻木。
- 显示：字幕框右下角多一行**粉字** `好感 +N`（在 `render_subtitle()` 里画，不另开窗口）。
- 记账：`state.json` 的 `affection`；设置 →「角色」页显示"现在 N"，旁边一个**清零**按钮。
- 结算：点暂停的那一刻结一次账，日志写一行「好感 · 这一段 +N · 累计 M」。

**三处措辞**

| 原来 | 现在 |
|---|---|
| 「我手心有点**潮**」 | 风格里加了一条：说人身上的感觉别用译制腔，手心出汗就说手心出汗 |
| 「刚才有人**冲我**说话」 | 气泡只是**旁边有人说话**，不是冲你来的：信号措辞、`65_分支`、红线三处一起改 |
| 模型偶尔整段不给【说】【态】【据】 | 以前 A1 判"没写引用"→ 整格吞掉。现在先提醒重写一次；第二次仍没标签就**收下台词**（A1 记「未标注」），别因为格式丢话 |

顺带：红线里补了句「每格固定三行，少一行这格就废了」。

真模型复验：`心动=是` 正常产出（`左边那个大冰淇淋桶，粉的，我一眼就被它拽住了…你陪我过去看一眼`），
气泡场景里她说的是「刚才那句"没事撞我干嘛"，听着就烦」——不再当冲她说的。

**11. 「想进去看看」终于能说了（2026-10-23 深夜）**

为什么以前不说——四层：v3 的目的系统被整段删了；`25_她的生活` 里那句「路过书店唱片店就想进去翻两下」
被自己标了「不许当眼前用」；没有任何分支是"看到一家店"；A4 要求最后一句有"你"，"进去看看吧"直接被判掉。

做法选了**代码控制频率**（方案 C），理由是 A（只改提示词）保证不了"偶尔"——模型可能一次不来，也可能连来三句。

| 改动 | 位置 |
|---|---|
| `SHOP_EVERY = 20`（格 = 100 秒）、`SHOP_CHANCE = 0.35`；只在**本来就要开口**的格子上加成 | `router.tick` |
| 命中时往分支块加一句：「可以顺口说一句：想进那家店看看。对他说，不等他答应；一句就够」 | `contract.build_blocks` |
| 红线加一条：「想进哪家店、想去看什么，可以说出来；但里面什么样你不知道，别编」 | `12_契约` 两套 rules |
| `25_她的生活` 里「想进去翻两下」从"一律不许"改成"这条可以说" | 人物设定 |

代价：命中那一格 +29 token，其余 0。实测频率（最坏情况：每格都有招牌）**300 格 10 次 ≈ 每 2.5 分钟一次**。

**顺带把 A1 放松了一档**：只有 A1（接住上一句）不过、A3/A4 都过时，**不再丢整格**，收下并记 `a1_soft`。

> 触发原因是实测抓到的一句：「左边那个大冰淇淋，粉得跟假的似的…**招财宝，你带我进去看看，就看看**。」
> 上一句是「我脚有点酸」——两句本来就没词可接，A1 判死，整格吞掉。这种句子丢了太可惜。

真模型复验：「左边那个大冰淇淋，粉得晃眼，我一眼就看见那几个字了 / **招财宝，你带我进去看看**」。

**12. 好感判定的两个洞（2026-10-23 深夜）**

现象：`state.json` 累计 +5，日志只记到一笔 `好感+4`（那句「我刚才那句不算…你手上使劲点」），
另外 1 点没有日志——对应的是「那块粉色的招牌…你带我过去看看」那一格。
同时第一句出现了「我讲那些旧事讲得嘴都干了，**你倒是给点反应啊**」——他要的是哑巴主角的反应。

两处都是**题词工程的定义太宽**，不是代码 bug：

1. `心动` 原来写的是「好看、喜欢、舍不得走、想多待一会儿」——"喜欢"把"想要某样东西"也算进去了，
   于是"看到一块招牌想进去"变成了心动。
2. 契约只写了「他不会开口」，没写「他不会有反应」，所以"给点反应"这类话没有东西拦。

修法：

| 改动 | 位置 |
|---|---|
| 心动收窄成两条：① 画面本身让你心里软了一下（花、光、水、颜色、风）；② 这一格高兴或害羞。明确"读字、想进的店、他做了什么"都不算 | `60_输出格式` |
| 代码兜底：句子带「招牌/牌子/写着/几个字/念」的，除非情绪是开心/害羞，否则不算好感 | `contract.heart_counts()` |
| 契约加一句：他不会开口，**也不会有反应**；别问他"怎么不说话"，别要"给点反应" | `12_契约` 两套 rules |
| 代码拦：出现「给点反应/给个反应/应一声/说句话/回答我…」直接判不合格、重说一次。不写光秃秃的"反应"，免得误伤"我反应慢" | `contract.asks_reaction()` |

真模型三格复验：`心动=是` 只落在"粉得晃眼""红得挺扎眼"这种画面句上，没有再出现向他要反应的说法。

**剩下的边界**：代码只能拦住"读字类"。**"觉得好看"还是"想要"最终是模型的判断**——
一句「粉得晃眼，我请你」既像好看也像想要。如果你的标准更严，可以只认审美分支，
代价是"花/水/远处那片颜色"这种落在接话格的句子也会被漏掉。

**13. 好感要"夸出来"才算（2026-10-23 深夜）**

实测那一笔：

```
那条坡往上拐，两边的墙都爬满了绿的，我眼睛一下就松了。
刚才那两句吵得我头疼，这会儿倒静下来了。你走慢点，我跟着。   → 好感 +4
```

这句在**描述**（墙爬满绿）、在**写身体**（眼睛松了、静下来了），但**没有一句在夸它**。
好感却加了——因为判定只要求"心里动了一下"，而"眼睛松了"被当成了动心。

改成：**填是之前，台词里必须真有一句在夸这个画面**——「真好看」「没白来」「你倒是挺会挑地方」
「想在这儿多站会儿」。只描述、只写身体松了，不算；补一句，才算。

代码兜底（`contract.heart_counts`）：

```
那条坡…眼睛一下就松了。                → 不加（只描述+身体）
那条坡…真好看。                       → 加
没想到还能看到樱花，真好看。             → 加
拐过来敞亮多了，你带我进去看看。（开心）   → 加（高兴）
那块粉色的招牌…你带我过去看看。           → 不加（读字/想要）
```

真模型三格复验：三格都是 `心动: 否`——一格是气泡、一格是冰淇淋招牌、一格是回忆，
**确实没有可夸的画面，就不该加**。这一版是"宁可不加，也不乱加"。

**14. 正面情绪直接写字幕上，负面留给观众猜（2026-10-23 深夜）**

要求：开心/害羞/感动的句子要加分，但**情绪本身也得出现在字幕里**；难过这类不写出来，
让人自己看出来——避免"情绪过山车"。

做法：

- 字幕框**左下角**多一个小标签 `（开心）`／`（害羞）`／`（感动）`，颜色分别是暖黄、粉、暖橙；
  右下角仍是 `好感 +N`。两个标签共用同一行，不影响正文。
- **只显示这三种**：`overlay.MOOD_C` 里只有开心/害羞/感动；难过、生气、害怕不画标签。
- 好感也跟着这三种走：`contract.heart_counts()` 的第一条就是 mood ∈ {开心, 害羞, 感动}。
- 情绪枚举加 `感动`（`brain.VALID_MOODS` + `60_输出格式`）。
- `20_风格` 加一条：**不要给情绪命名**——正面可以直接写在脸上，负面用动作、停顿、改口带出来。

实测那句「拐过来敞亮多了，你带我进去看看。（开心）」现在会长这样：

```
             “拐过来敞亮多了，你带我进去看看。”
（开心）                          好感 +4
```

正面/负面各渲染了一张对照图，负面那条只有好感、没有情绪标签。

**15. 好感/情绪的两个"感觉不对"（2026-10-23 深夜）**

**① 4~5 看着很多——先看是不是没重启**

`main.py` 的最后修改是 23:51:35，而日志里 23:53–23:54 仍在出 `好感+4`。
同一段 11 次加心里 8 次是 4~5——在新权重下这个概率约万分之一。

**16. 开头不再千篇一律 + 故事只讲"最近的事"（2026-10-24 凌晨）**

**① 开头为什么总是"我看见……"**

`20_风格` 的 look 段原来写死了四个例子（一块亮、一处字、一个挡在面前的东西、一个正对着你的人），
而且**每一格都发**。四条通道本来就有限，等于每格都在同一批开头里挑。

改了三处：

| 改动 | 效果 |
|---|---|
| look **只在事件格**给（读字/气泡/过渡/靠近/回访）；接话格和故事格不给 | 续锚时从上一句起手，不再"先看画面" |
| 分支块去掉对事件的**复述**（原来"旁边有人说了句话"和信号块的"旁边有人说了句话（左上）"重复），只留"怎么做" | 同一件事只说一遍，不用换个说法再讲一次 |
| look 的四个例子删掉，改成「从这一格真正打到你的那样东西起手」 | 例子会被当清单抄，删掉反而发散 |

**② 故事不要往童年跑**

原来写的是"以前的事（几岁、什么季节）"，模型就一路"我十二岁那年…"。报具体年龄最容易露：
别处的设定对不上，一听就假。

- 提示词改成**最近的事**：前几天逛的街、上次去哪儿玩、吃到的一顿、路上碰到的一件小事；
  要细节就写"哪天、在哪、手里拿着什么"，**不写年龄**。
- 契约和人物设定里的"小时候"也一并改掉（"在类似的老街住过一阵"）。
- 代码兜底：`contract.childhood_mention()` 命中「小时候/童年/儿时/岁那年/那年我/小学」就重说一次。
  实测第一版仍然冒"我小时候那条街口…"，拦下重说后变成：

```
去年冬天我买过一盆薄荷，放窗台上，天天浇水，浇得叶子全黄了
我端着盆去问楼下卖花的大姐，她扒开土看了一眼，说水多了，根泡烂了
```

**仍然会重复的地方**：同一个东西被"续锚"连说 2–3 格（比如那家粉色冰淇淋店）。
那是线程设计本身（一条话题允许连说几格），不是开头模板。

**17. 清空记忆清了，但她还在聊旧事（2026-10-24 凌晨）**

原因很简单：`Memory.clear()` 只清了**记忆文件**（entries / digest / router_state），
但**正在跑的 Router 对象**里还挂着两样东西：

- `thread`：正在聊的那件事（锚 + "你已经说到哪儿"）
- `pending`：还没结的账（欠的那句话、想让他做的事）

下一格它照常 `save_router(snapshot())`，又把这两个写回 `memory.json`——
于是你看到的是"记忆清了，话题还在"。

修法两处：

| 改动 | 位置 |
|---|---|
| 新增 `Router.reset()`，清 `thread/pending/hist/win/memo/tick_no` 等全部运行时状态 | `router.py` |
| 「清空记忆」先 `mem.clear()`，再 `router.reset()` + `save_router()`；确认框里写明会连"正在聊的那件事"一起清 | `settings_ui.py` |
| 自愈：启动加载时，若 `entries` 为空却还留着 `thread/pending`，直接丢掉（清理没干净留下的孤儿） | `memory.py load()` |

实测：

```
清空前         含旧事 = True   含旧话题 = True
只清记忆文件    含旧事 = True   thread 还在 = True     ← 这就是你遇到的
连 Router 一起清 含旧事 = False  thread = None
```

**好感不在记忆里**：它是 `state.json` 的 `affection`，清记忆不会动它，要用「角色 → 清零」。

**18. 气泡其实就是路人说话——不该让她回应（2026-10-24 凌晨）**

现象：29 条台词里有 **7 条**是被气泡触发的，内容都是「旁边有人说话」「那声'什么意思'还撞我耳朵里」
「听着像在喊我」。可这些是路人的话，跟她没关系。

根子在两处：

- 气泡原先是**最高优先级 5**——比读字还高，一句路人台词就能把她正在说的话题踢掉；
- 它还在**抢断名单**里（`_preempt_allowed` 明确写「气泡可以抢」）。

等于每来一句路人台词，她既要回应，又要被打断。难怪笔记里全是"旁边有人说话"。

改法：

| 改动 | 位置 |
|---|---|
| 优先级 5 → **1**（和审美并列最低），读字/过渡都排在它前面 | `PRIO` |
| 从抢断名单移除——`THREAD_BREAK=3`，优先级 1 永远不够，不再打断进行中的话题 | `_preempt_allowed` |
| 分支文案改成：「路边有人说话，跟你没关系。最多嫌一句吵，别当是叫你，也别接。」 | `65_分支` |

实测（回放测试1，30 格）：

```
改前：续锚 18 / 读字 5 / 闲话 3 / 审美 1 / 过渡 1 / 气泡 若干（会抢话题）
改后：续锚 20 / 读字 5 / 闲话 3 / 审美 1 / 过渡 1 / 气泡 0
```

开口从 12 降到 10，续锚从 18 升到 20——**话说得更连贯了**。

真模型三格：一句"旁边有人说话"都没有，变成了
「招牌上写的是 Felicita / 你带我进去吧，我先挑个口味」。

**副作用**：气泡这条通道基本不再触发（被读字和过渡盖住）。如果你想偶尔留一句"嫌吵"，
把 `PRIO["bubble"]` 调到 2 就行——比欲望低，但不会被彻底盖没。

**19. 故事要有"最后一格"，以及"收回"这个说法（2026-10-24 凌晨）**

**① 故事为什么老是不收尾**

线程确实是 4 格（`thread_life=4`），但**没有任何一句告诉模型"这是最后一格"**。
`thread_block` 每格的措辞一模一样，最后线程静默清零（"说满收摊"）。结果两种：要么讲一半断掉，
要么硬拖着讲，直到没劲。

改：`remaining <= 1` 时，线程块换一句话——

```
这是这件事的最后一格：用一句「后来」「所以我」「打那以后」把它收住，
收完就放下，别再起新的事。收尾之后可以顺手把话头交回眼前。
```

实测四格（同一段故事）：

```
[1] 剩4格  前几年我养过一只小狗，黄毛的，特别馋 / 有回我蹲在门口啃馒头，它凑过来把整个馒头叼走了
[2] 剩3格  后来那狗自己跑丢了，我找了三天，巷子口贴了纸也没人回话
[3] 剩2格  那三天我天天绕到巷子尾去喊它，嗓子喊哑了也没应 / 后来我就不养狗了，改喂楼下的野猫
[4] 剩1格  打那以后我就不喂了，省得惦记 / 倒是你，走这么久也不说歇，我脚底板都磨热了
```

第四格就是"开头—中间—中间—结束"，结束还顺手把话头交回眼前。

**② "收回"这套说法**

模型说过：「我刚才那句收回，水的事先放放。」——听着像在改稿。出处有三处：

| 位置 | 原文 |
|---|---|
| `contract.ACTION_REFS` | 动作引用里有"收回" |
| `50_记忆说明` | 「可以说『我刚才那句不算』」 |
| `40_句式池` | 起手式里有一条「先把上一句收回来」 |

三处都删了/换了：动作引用只剩 追问/改口/自嘲/补完/认输/顶回去/绕过；起手式改成"先补一句刚才没说完的"。
现在把「收回」当动作引用会被 A1 判不合格（实测→False）。

**还没动的两处**（你说过"故事过多"）：`LANG_EVERY=4`、`follow` 分支里那句"把话拐到你自己身上"。
如果加了"最后一格收尾"之后仍然觉得多，这两处再收。
